# Mobile first-screen revision — user feedback

User wants the opening screen to capture attention immediately on a phone, rejects tiny uppercase slogan labels, and is open to typewriter-style data motion. Preserve the ongoing onboarding and Vercel deployment task.

Direct build: a concrete free-preview offer in a shorter left-aligned heading, normal-size supporting text, primary onboarding CTA, and an immediately visible compact live map scene. On mobile, a typed business query changes the illustrative record, while map and single business card stay visible without a 600px diagram pushing proof below the fold. No animated marketing headline or decorative eyebrow. Existing Shortimize motion research owns the product demonstration approach; existing Veriburada brand owns palette and type. Native code is appropriate; adding React solely for a typewriter is unnecessary.

Accessibility: full static text for reduced motion, no character-by-character screen-reader announcements, button focus does not keep shifting, and animations suspend while onboarding is open or tab is hidden. The scene is labeled illustrative; no fake real search count.
